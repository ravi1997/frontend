# User Stories

## Creator Stories

- **As a Creator**, I want to **drag and drop fields** into a form, so that I can **build forms without writing code**.
- **As a Creator**, I want to **save my form as a draft**, so that I can **continue working on it later**.
- **As a Creator**, I want to **preview my form**, so that I can **see exactly what the respondents will see**.

## Administrator Stories

- **As an Administrator**, I want to **see a dashboard of all forms**, so that I can **monitor activity and status**.
- **As an Administrator**, I want to **manage user roles**, so that I can **control who can create or publish forms**.

## Respondent Stories

- **As a Respondent**, I want to **access public forms via a slug**, so that I can **easily submit my data**.
- **As a Respondent**, I want to **see validation errors clearly**, so that I can **fix my inputs before submitting**.
