## Detailed Risk Analysis

### R-VW-001: Infinite Execution Loops

**Risk Description:**
Logical errors by users (e.g., Node A -> Node B -> Node A) can cause infinite loops, crashing worker pods and inflating costs.

**Mitigation Strategies:**

- **Static Analysis**: Perform Depth-First Search (DFS) on the graph during save to detect cycles in synchronous paths.
- **Runtime Guard**: Inject a `depth` counter in the workflow context; terminate execution if it exceeds 100 steps.
- **Circuit Breaking**: If a specific workflow fails 3 times consecutively, auto-disable it and notify the owner.

### R-VW-002: Code/Expression Injection

**Risk Description:**
Users may input malicious expressions (e.g., `__import__('os').system('rm -rf /')`) in condition nodes.

**Mitigation Strategies:**

- **Restricted Environment**: Execute all conditional logic in a restricted Python sandbox (e.g., `RestrictedPython` or a Docker-in-Docker layer).
- **Validation**: Enforce a strict Allow-list of supported variables and functions in the expression engine.
- **Audit Trails**: Log the exact input and evaluated result of every expression.

### R-VW-003: Worker Pool Exhaustion

**Risk Description:**
A single user triggering 10,000 workflows simultaneously can starve the system for other tenants.

**Mitigation Strategies:**

- **Rate Limiting**: Implement a leaky-bucket algorithm per `tenant_id` for workflow triggers.
- **Dedicated Queues**: Use separate Celery queues for 'System Critical' vs 'User Automation' tasks.
- **Auto-Scaling**: Scale the worker pool based on the length of the pending task queue.

### R-VW-004: Partial Execution State Loss

**Risk Description:**
A server crash during a multi-step workflow may leave data in an inconsistent state (e.g., Email sent, but DB not updated).

**Mitigation Strategies:**

- **Idempotency**: All custom actions (e.g., "Send SMS") must support idempotency keys to prevent duplicate actions on retry.
- **Checkpointing**: Save the execution state and variable context to MongoDB after every successful node transition.

## Contingency Plans

### Loop Detection Failure

1. Identify the rogue worker via Prometheus metrics.
2. Manually kill the worker process.
3. Patch the Graph Validator to include the specific edge case.

### Security Breach

1. Immediately shut down the Workflow Execution service.
2. Revoke all API keys generated by the compromised workflow.
3. Perform a full audit of system logs to identify lateral movement.
